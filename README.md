# Scattered Floating Video Gallery

Interactive 3D scattered motion section inspired by multi-directional entrance animations.

## Files
- `index.html`: Main HTML structure containing the scattered video elements and center hero text.
- `style.css`: 3D transform, directional fly-in keyframes, and hover effects.
- `script.js`: Mouse parallax tilt tracking.

## Usage
Simply unzip and open `index.html` in any modern web browser.
